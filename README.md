# 📚 Flask Dictionary API

This project provides a simple, browser-accessible API that returns word definitions from a local CSV-based dictionary. It also includes a homepage with usage instructions.

---

## 🚀 Features

- REST API endpoint to retrieve definitions for any word
- Homepage with example usage
- CSV-based backend for easy extensibility
- Case-insensitive word matching
- Built with Flask

---

## 🔧 Technologies Used

- Python
- Flask
- pandas
- HTML (basic homepage)

---

📘 Real-World Applications
- Lightweight backend for language learning tools
- Vocabulary lookup in chatbots or educational apps
- Custom dictionary API for internal documentation or style guides
